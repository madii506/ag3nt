      Questions

      Are the agents AI?

      No language model decides anything. Each agent is a fixed program with one job that reads public Solana data: RPC, pump.fun's coin records, Jupiter quotes and Dexscreener. The same input gives the same reading, and every case file lists the steps it took.

      Do I have to connect a wallet?

      No. Eight agents only read. OTTO can also close your empty token accounts and send the rent back to you; only then does your wallet show a transaction to sign. Closing an empty account moves no tokens.

      How sure is a verdict?

      A verdict is what the chain shows at that moment: CLEAR means nothing the agent checks raised a flag, not that a coin is safe. Each flag says exactly what triggered it, so you can check it yourself on Solscan.

      Why did KESTREL refuse a coin?

      To find the launch block it walks the coin's history back to the first transaction. Coins with more than 8,000 transactions are too long a walk for one request; CENSA still reads their holders.

      Are cases really public?

      Yes. Every run is stored with its result and gets a case number and a link. The inputs are public addresses, so nothing private is kept. Don't paste anything you wouldn't post.

      What does $AG3NT do?

      It's the coin of the unit. The agents work with or without it, and nothing on this page is paid. When it launches, the address shows under the search box on this page first. Anyone posting a CA before that is not us.

      Are VERA, KESTREL and the rest real AI models?

      No. They are our agents' codenames. None of them is a language model or a product from an AI company; each is a fixed program that reads the chain.

      Is AG3NT part of pump.fun?

      No. AG3NT is independent. It reads public pump.fun and PumpSwap data the same way anyone can.
