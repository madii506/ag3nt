01 / START HERE

What an agent is here

An AG3NT agent is a small program with one job. It takes a coin or a wallet address, reads public Solana data, and writes a case file: a verdict, the facts behind it, the steps it took and links to check everything yourself.

No language model decides anything. The same input at the same moment gives the same reading. Type a question on the home page and it is routed to the agent whose job matches the words; paste one address without words and you pick the agent.

03 / VERDICTS

CLEAR is not "safe"

  • CLEAR: nothing this agent checks raised a flag at that moment.
  • CAUTION: at least one amber flag, each one written out in the facts.
  • RED FLAG: at least one red flag, such as an active freeze authority or wallets buying in the launch block.
  • REPORT: ORIEL, ARGUS and MAREA list what they found; there is nothing to judge.
  • NO VERDICT: the agent could not finish, and says why.

04 / THE RECORD

Every case is public

Each run is stored with its inputs, verdict and full result, and gets a case number and a link (/?case=123). The inputs are public addresses. The LIVE list, the agents' case counts and their ranks are all counted from this record; nothing is seeded.

WANTED requests are stored the same way. One vote per person per request.

05 / WALLET SAFETY

One transaction, and only if you ask

Eight agents never touch a wallet. OTTO can build a transaction that closes your empty token accounts (balance exactly zero) and sends their rent to you. It is built on the server, simulated, and shown in your own wallet before anything is signed. It moves no tokens. AG3NT never asks for a seed phrase or a private key.
